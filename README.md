# security-skills

A Claude Code plugin providing skills for writing security findings, incident reports, and executive summaries in neutral, defensible language. These tools help security teams communicate vulnerabilities, incidents, and risk assessments with clarity and precision.

## Skills

<!-- finalized in Task 8 -->

- **security-language** - Assist with writing security-neutral language in findings and reports
- **verify-security-language** - Verify that security language meets neutrality and defensibility standards
- **write-security-finding** - Create structured security findings with impact and recommendations
- **write-security-incident-report** - Draft comprehensive incident reports with timeline and analysis
- **write-security-executive-summary** - Summarize security issues for executive and board audiences

## Install

Install via the `/plugin` marketplace command in Claude Code, or clone this repository into your Claude Code plugins directory.
